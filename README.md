# wotw mod — бета для Garry's Mod

**Установка:** скачай `wotw_mod_beta.zip` с [ветки проекта](https://github.com/romanata10/war-of-the-worlds-gmod/tree/arena/9f013870-war-of-the-worlds-gmod), извлеки папку **`wotw_mod`** в `garrysmod/addons/` и перезапусти игру. **Удали старую папку `wow_tripods` из `addons/`, если ставил прошлую бету**, иначе NPC будут задвоены. В Sandbox смотри раздел **Entities → wotw mod**. Для движения NextBot требуется navmesh: на карте без него выполни `nav_generate` в консоли администратора (карта перезагрузится).

## Четыре машины

| NPC | Действие | Внешний вид в этой бете |
| --- | --- | --- |
| Красная тренога | Тепловой луч | Реальная геометрия из `tripods_the_tripods_1984.glb`, процедурное движение ног; **исправлена перепутанная модель**. |
| Белая тренога | Топчет вблизи (до 150 ед.), вытягивает световую клешню из центра на расстоянии до 360 ед., подтягивает и ассимилирует игрока. NPC после захвата заменяется солдатом. | Вторая модель из GLB, правильное назначение. Сама клешня — световой эффект, **не 3D-рука**. |
| 1953 Tripod | Парит, движется по воздуху, стреляет смертельным красным лучом. Синий щит выдерживает 3 попадания RPG; после ещё 4 попаданий RPG машина погибает. Снизу выдвигается камера на тросе длиной до 350 ед.; преграды останавливают её. | **Временная стандартная модель-заглушка**. |
| Spider Tripod | Быстро преследует цели, стреляет пулемётом; вблизи выпускает 4 тентакля, хватает и пронзает цель. | **Временная стандартная модель-заглушка**; тентакли — эффекты. |

Для красной и белой треног: клиентский рендер теперь использует непрозрачный двусторонний материал, правильный порядок граней, поворот модели в направлении движения и масштаб **1.35×**. Модели новых машин не увеличиваются. Рендер, анимация и полёт требуют проверки в настоящем GMod — в этой среде игра не установлена.

**Важно:** пользователь упомянул две новые 3D-модели, но файлов `1953 tripod` и `spider tripod` в этой ветке пока **нет** (в репозитории находится только `tripods_the_tripods_1984.glb`). Чтобы заменить заглушки настоящей геометрией, добавь файлы `.glb`, `.gltf` с текстурами или `.obj` в репозиторий либо прикрепи их к сообщению и скажи, какая модель какая. Код проверяет `models/wotw_mod/tripod_1953.mdl` и `models/wotw_mod/spider_tripod.mdl`, если они будут скомпилированы позже.

Если установлен [DrGBase](https://github.com/Dragoteryx/drgbase), в разделе NPC также появляются отдельные версии красной и белой треног на `drgbase_nextbot`. Обычные версии автономные. VJ Base не требуется. Захваченный игрок сохраняет управление, получает модель солдата, AR2 и дубинку до смерти. Луч и клешня проверяют препятствия трассировкой.

### Сборка альтернативных Source-моделей

Исходный GLB содержит две статичные машины без анимаций. `python3 tools/build_models.py` создаёт `generated/source_models/tripod_red.qc`, `tripod_white.qc`, SMD и клиентскую геометрию (файлы **уже включены** в ZIP). При желании можно скомпилировать оба QC через Crowbar/`studiomdl` для GMod и поместить результаты в `wotw_mod/models/wow_tripods/`. `.mdl` не требуются для клиентского отображения красной/белой машин, но эта компиляция здесь не проверена.

**Источник исходной модели:** Rebus2077, [Tripods (The Tripods 1984)](https://sketchfab.com/3d-models/tripods-the-tripods-1984-69c0be9225d34a8c91d028c5e046cf0c), CC BY 4.0. Сохраняйте атрибуцию при распространении. Изменения: разбиение моделей, риг, анимация, материалы и игровая логика.
