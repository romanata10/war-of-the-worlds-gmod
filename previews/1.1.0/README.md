# Превью NPC версии 1.1.0

Это **офлайн-рендеры**, созданные по размерам, форме и палитре процедурной геометрии из `lua/autorun/client/wotw_generated_models.lua`. **Не скриншоты из Garry's Mod.** Для читаемости силуэтов освещение на картинках светлее, чем может получиться в конкретной игре. Эффекты выстрелов, настоящие карты и анимация не показаны. Рендеры созданы скриптом `tools/render_npc_previews.py` (Python, numpy, matplotlib, Pillow).

- `pendragon.png` — Pendragon Pictures Tripod.
- `walker.png` — The Asylum Walker на наклонной схематичной поверхности.
- `bbc2019.png` — BBC 2019 Tripod.
- `asylum2.png` — The Asylum WOTW 2 Tripod (ноги в разложенном состоянии).
- `overview.png` — быстрый обзор четырёх отдельных превью.

**Walker:** визуальные точки опоры вычисляются трассировкой лучей вниз и в сторону стены, сглаживаются между кадрами, затем строятся два сегмента конечности и колено. Это не физические ноги с коллизиями и не полноценная IK/навигация по отвесным стенам. Сервер отдельно пробует поднимать корпус вдоль стены до уступа; этот механизм нужно проверять на конкретной карте с navmesh.
