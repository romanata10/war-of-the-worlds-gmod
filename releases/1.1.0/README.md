# wotw mod 1.1.0 (бета)

[Скачать wotw_mod_1.1.0.zip](wotw_mod_1.1.0.zip) — нажмите **Download raw file** на GitHub. В архиве установочная папка **`wotw_mod`**; замените предыдущую версию в `garrysmod/addons/`, не устанавливайте две одновременно.

## Изменения относительно 1.0.0

- Четыре новых NPC, вдохновлённых предоставленными кадрами: Pendragon Pictures, The Asylum Walker, BBC 2019, The Asylum WOTW 2. У каждого собственная иконка в меню; пока это **оригинальные упрощённые процедурные 3D-формы**, а не точные модели из фильмов.
- Pendragon захватывает задними клешнями. Walker пытается преодолевать уступы, его ноги подстраиваются под карту. BBC 2019 выпускает синий электрический импульс. WOTW 2 складывает ноги и планирует при падении/погоне.
- Тепловые лучи красной треноги и 1953 теперь стреляют с разбросом и иногда промахиваются; новые машины тоже пользуются этой баллистикой. Зелёный глаз Walker стреляет зелёным лучом. У Spider увеличен разброс пулемёта.

**Ограничения:** полное лазание по отвесным стенам и физически достоверный полёт здесь не гарантируются, точные 3D-модели для четырёх новых NPC не предоставлены. Бета не тестировалась в установленном Garry's Mod. Скриншоты, переданные пользователем, использованы для иконок; при публичном распространении проверьте права на них.
