# wotw mod 1.0.0 (beta)

[Скачать `wotw_mod_1.0.0.zip`](wotw_mod_1.0.0.zip) через кнопку **Download raw file** на GitHub.

Распакуйте **только папку `wotw_mod`** из архива в `garrysmod/addons/`. При обновлении замените старую `wotw_mod`; не держите две версии одновременно. Если осталась очень старая папка `wow_tripods`, удалите её во избежание дублей.

Включены четыре NPC и их исходные модели: красная и белая треноги, 1953 Tripod, Martian Spider. Для 1953 и Spider добавлены процедурные движения; исходные GLB не содержат готовых анимационных клипов. Бета не тестировалась в установленной игре — подробные ограничения и атрибуция моделей в `wotw_mod/README.md` внутри архива.
